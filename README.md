# GRAVITY — N-Body Physics Playground

GRAVITY is a space simulation I made using HTML, CSS and JavaScript. The main idea was to make a small interactive space where I could spawn planets, stars, comets and black holes and see what happens when gravity starts doing its thing. Objects can orbit each other, crash into each other, or get completely thrown off because apparently space does not care about stability.

I used AI to help me with some of the JavaScript structure, physics calculations and maths behind things like gravity and velocity, but I still had to test everything and figure out a lot of the problems myself. There were quite a few bugs along the way, like objects flying off into nowhere, weird collisions, gravity behaving like it had a personal problem with certain planets, and features breaking when I changed something else. So a big part of making this project was debugging, changing the code, testing it again, and repeating that process until things finally started behaving.
